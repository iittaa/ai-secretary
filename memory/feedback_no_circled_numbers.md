---
name: 丸付き数字（①②③）は使わない
description: 丸付き数字は見づらいので、普通の数字（1. 2. 3.）かハイフンで番号をつける
type: feedback
---

質問やリストで番号をつける時、丸付き数字（①②③④⑤⑥⑦⑧⑨⑩）は使わない。

**Why:** 表示が見づらい（ユーザー談「みづらいからまるつきの番号やめれる？」）。フォントによっては潰れて読めないこともある。

**How to apply:**
- 普通の数字 + ピリオド：`1. 2. 3.`
- またはハイフン：`- xxx`
- 質問項目の番号も普通の数字で
- リスト・選択肢どちらでも適用
