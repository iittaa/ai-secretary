name: 長文出力はpbcopyでクリップボードに送る
description: ターミナル上の長文はコピーしづらいので、pbcopyで自動的にクリップボードへ送ると喜ばれる
type: feedback
---

長めのテキスト（チャット送信用文面・コピペ前提のスニペット・コマンド結果など）を出力する時は、`pbcopy` で自動的にクリップボードに送る。

**Why:** ターミナル上の長文は手動コピーが面倒（ユーザー談「ターミナル上だと少しコピーしづらくて」）。pbcopyを知って驚いていたので、知らない便利技として継続的に活用すると価値が高い。

**How to apply:**
- 100文字以上のチャット送信用テキスト → 自動で `pbcopy` に流す
- コマンド：`cat <<'EOF' | pbcopy ... EOF`
- 完了後に「✅ クリップボードにコピー完了！」と知らせる
- 必要に応じてファイル保存も提案（`/tmp/` などに）
- macOS環境（darwin）でのみ有効
